# crazy-cribbage

Cribbage Roguelike

## Rewards

At the start of a run and halfway through each round, choose a card and an
improvement that stays with that card for the run. Improved cards can benefit
either side that plays or scores them. Show-scoring bonuses for the newer card
improvements require the improved card to be in the hand or crib, not just the
starter. Crazy Eight can be played as 1 or 8 during pegging.

After winning a round, choose an ability for the rest of the run. In Classic,
abilities benefit the player, not the AI; in Twin Hands, they benefit both
controlled hands. Wheel of Fortune spins once per deal, displaying a scoring
effect for that hand.
